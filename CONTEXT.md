# asbplayer

Language for discussing subtitle display and navigation.

## Language

**Caption track**:
A set of timed subtitle lines supplied for a video in a particular language. A TikTok caption track may contain creator-provided text, automatic captions, or a supplied translation.
_Avoid_: Caption when referring to the video's untimed description

**Native captions**:
The captions displayed by the video website's own player, separate from asbplayer's subtitle display.
_Avoid_: Subtitles without specifying whose display is meant when both are present

**Video navigation**:
Moving from one video to another, such as moving to the next TikTok clip.
_Avoid_: Navigation without stating whether it refers to videos or subtitles

**Subtitle navigation**:
Moving the playback position between timed subtitle lines within the same video.
_Avoid_: Navigation without stating whether it refers to videos or subtitles
